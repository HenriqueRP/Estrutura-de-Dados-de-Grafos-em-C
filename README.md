# Estrutura de Dados em C
Uma implementação de TAD de grafos na linguagem C.
# Implementação
A maneira que decidi implementar o TAD de grafo foi pela representação em lista de adjacência, usando uma lista duplamente encadeada para os vértices, os quais tem referência para uma lista de arestas incidentes. Ambos possuem suas próprias implementações, com tipos, structs e operações. Ele segue a ideia de ocultamento de informação com interfaces tendo apenas as operações que podem ser realizadas na estrutura.
# Objetivo
Estudar a estrutura de um grafo de maneira computacional, praticar a criação de estruturas de dados e também a programação na lin-guagem C.
